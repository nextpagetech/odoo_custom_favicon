Odoo 18 Branding

Custom Favicon & Branding

Customize the browser-facing identity of Odoo with your own application title, favicon, PWA app icon and brand promotion logo. The addon also supports documentation redirection and selected interface debranding so organizations can present a more consistent internal brand experience.

Key Features

Custom Browser Title Set the application brand name used in browser page titles.
Custom Favicon Upload an ICO, PNG or SVG favicon from Odoo Settings for use in browser tabs.
PWA App Icon Upload a branded app icon used for browser installation prompts and installed shortcuts.
Brand Promotion Logo Use an uploaded promotion logo, with the active company logo used as a fallback.
Documentation Redirect Redirect supported backend documentation links to your preferred documentation URL.
Selected Interface Debranding Rewords or removes selected Odoo references across supported dialogs, import helpers, onboarding, offline pages and related interface areas.

How It Works

  1. Install the addon and open the relevant General Settings.
  2. Enter the application title you want users to see.
  3. Upload a favicon, optional PWA icon and optional promotion logo.
  4. Configure a documentation redirect URL when required.
  5. Save the settings and refresh the browser to see the configured brand identity.

Configure Your Brand

Branding controls are exposed through Odoo Settings so administrators can manage the application title, favicon, PWA icon, promotion logo and documentation URL without editing core Odoo files.

Consistent Browser and App Identity

The configured identity is reused across browser tabs, the PWA web manifest, brand promotion areas and supported documentation links.

Additional Included Customizations

This package contains active customizations beyond favicon management. They are disclosed here so customers understand the complete installed scope.

  • Selected settings, dialog, mail, onboarding, import and documentation-link branding changes.
  • Database-manager and offline-page presentation changes.
  • Inventory reordering-rule automation and custom reordering-rule views.
  • Sales-timesheet project/task creation adjustments included in the active Python load path.
  • User notification/onboarding and related mail behavior adjustments included in the package.

Compatibility

  • Odoo 18.0
  • Technical addon name: npt_custom_favicon
  • Requires the Odoo modules declared in the manifest.
