Odoo 18 Branding Addon

Custom Favicon & Branding

Customize the browser-facing identity of Odoo from General Settings. Configure the application title, favicon, PWA icon, brand promotion logo, and documentation redirect without editing Odoo core files.

The package also includes broader UI and branding adjustments that replace or remove selected default Odoo references across backend dialogs, settings, mail/onboarding areas, the database manager, and related interfaces.

Key Branding Features

Application Title

Set the brand name used in browser page titles and selected branded messages.

Custom Favicon

Upload a favicon from General Settings for browser tabs and browser-facing pages.

PWA App Icon

Configure the icon used by the web manifest for install prompts and installed shortcuts.

Brand Promotion Logo

Upload a logo used in the branded promotion area, with company logo fallback.

Documentation Redirect

Redirect supported backend documentation links to a configured documentation URL.

Database & Offline Branding

Applies selected branding changes to the database manager and offline experience.

Configure Your Brand from Odoo Settings

Branding controls are available from Odoo settings. The configured title and uploaded assets are stored as system parameters and reused by the relevant browser and PWA endpoints.

Branding Across Key Touchpoints

The configured identity is reused across browser tabs, PWA installation, selected promotion areas and documentation links so users see a more consistent branded experience.

Additional Included Customizations

This package contains active customizations beyond favicon management. They are listed here so customers can understand the complete installed scope.

  • Selected Odoo wording, dialog, mail, onboarding and documentation-link adjustments.
  • Selected settings cleanup, including removal or replacement of some default help/upgrade elements.
  • Custom database-manager branding behavior.
  • Inventory reordering-rule automation and custom reordering-rule views.
  • Sales timesheet project/task creation adjustments included in the active Python load path.
  • User notification/onboarding and related mail behavior adjustments included in the package.

Compatibility

  • Odoo 18.0
  • Technical module: npt_custom_favicon
  • Requires the Odoo modules declared in the manifest.
